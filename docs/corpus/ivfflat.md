# IVFFlat 索引

IVFFlat（Inverted File with Flat compression）是倒排文件索引，属于基于聚类的近似最近邻算法。

## 结构
构建时用 k-means 把所有向量聚成 lists 个簇，每个簇一个中心点。查询时先算问题向量到所有簇中心点的距离，
只挑最近的 probes 个簇，在这几个簇内部做精确扫描。

## 两个参数
- lists：簇的数量，官方建议取 行数除以 1000（一百万行以下）。
- probes：查询时扫描的簇数，默认 1。调大召回上升、延迟上升，经验值从 lists 的平方根起步。

## 一个必须注意的构建时机
IVFFlat 的聚类结果依赖构建时已有的数据分布。表里没有数据时建索引会得到退化的簇划分，
所以必须先把数据灌进去再建索引；后续数据分布变化太大也要重建。HNSW 没有这个问题。

## 与 HNSW 的取舍
IVFFlat 构建快、内存占用小、批量导入友好；HNSW 召回更高、延迟更低但构建慢、占内存、写放大。
写多读少的场景 IVFFlat 更合适，读多写少、对延迟敏感的场景选 HNSW。
