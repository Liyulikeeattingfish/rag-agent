# BM25 打分

BM25（Best Matching 25）是信息检索里最经典的排序函数，是 TF-IDF 的改进版，也是 Lucene 和 Elasticsearch 默认的相关性算法。

## 公式
score(q, d) = 对 q 中的每个词 t 求和：IDF(t) 乘以 (tf(t,d) 乘以 (k1 + 1)) 除以 (tf(t,d) + k1 乘以 (1 - b + b 乘以 |d| 除以 avgdl))

三个部分各自解决一个问题：
- IDF(t) = ln(1 + (N - df + 0.5) / (df + 0.5))：词越罕见权重越高，把"的""是"这类高频词的贡献压下去。
- 词频饱和：分子分母里都有 tf，所以词频增长带来的收益是递减的，一个词出现 10 次并不比出现 5 次相关性高 2 倍。
- 长度归一化：b 控制文档长度的影响，长文档天然更容易命中词，要惩罚。

## 两个参数
- k1 默认 1.2，控制词频饱和速度，0 表示完全忽略词频。
- b 默认 0.75，0 表示不做长度归一化，1 表示完全归一化。

## 中文的问题
BM25 是词级的，中文必须先分词，常见做法是接 jieba、IK 或 PostgreSQL 的 zhparser，或者干脆引入 Elasticsearch。
没有分词器时可以用字符 n-gram 近似，本项目用二元组（bigram），这是免依赖的折中方案。
代价是看不见词边界，对同义词和词形变化无能为力。

## 和向量检索的分工
BM25 擅长字面精确命中（专有名词、错误码、型号），向量检索擅长语义泛化（换了说法的同一件事）。
两者互补，所以混合检索通常同时上，再用 RRF 融合名次。
