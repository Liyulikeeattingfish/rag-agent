# 向量化与 Embedding 模型

## 双塔结构
embedding 模型是双塔（bi-encoder）：问题和文档各自独立编码成向量，编码时彼此完全没见过面。
好处是文档向量可以离线算好存库，在线只算一次问题向量，所以能做到毫秒级检索。
代价是它只能捕捉粗粒度的语义相似，无法逐字比对——这正是后面要加一层重排的原因。

## 维度
维度越高表达能力越强，但存储和计算成本线性上升。本项目用 Qwen3-Embedding-0.6B，输出 1024 维。
表里 vector 列声明的维度必须和模型输出一致，否则写入时直接报错。换模型意味着必须重建表。

## 相似度与归一化
余弦相似度衡量两个向量的夹角，对向量长度不敏感。如果把向量预先做 L2 归一化，余弦相似度就等价于内积。
pgvector 里 <=> 是余弦距离（1 减去余弦相似度），<#> 是负内积，<-> 是 L2 距离。排序时越小越相似。

## 中文场景
中文没有空格，很多英文 embedding 模型在中文语料上表现明显下降。选型不能只看 MTEB 榜单，
一定要在自己的语料上跑评测——榜单排名和你的业务语料排名经常不一致。

## 一个容易踩的坑
pgvector 的 LangChain4j 集成返回的 score 不是余弦相似度，而是 (1 + 余弦相似度) / 2，
取值范围被压缩到 [0,1]。不知道这件事的话，相似度阈值会完全设错。
