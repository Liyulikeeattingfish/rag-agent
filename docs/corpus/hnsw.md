# HNSW 索引

HNSW（Hierarchical Navigable Small World）是分层可导航小世界图，属于基于图的近似最近邻算法。

## 结构
底层包含全部节点，每往上一层节点数按指数衰减。查询从最上层的一个入口点开始，在每层做贪心搜索逼近目标，
然后下沉到下一层继续细化，直到最底层拿到结果。上层负责快速跳到大致的区域，底层负责在局部精确地找。

## 三个参数
- m：每个节点在每层的最大连接数，默认 16。m 越大图越密，召回越高，但索引体积和构建时间也越大。
- ef_construction：构建索引时的候选队列大小，默认 64。调大能建出质量更高的图，但构建更慢。
- ef_search：查询时的候选队列大小，默认 40，通过 SET hnsw.ef_search = X 调整。
  这是唯一可以在线调、不用重建索引的参数。调大召回上升、延迟上升。

## 与 IVFFlat 的取舍
HNSW 召回率和延迟都更好，但索引体积更大、构建更慢，而且每次插入都要维护图结构，写放大明显。
IVFFlat 构建快、体积小，但必须先有数据再建索引，且查询只扫一部分聚类，召回对 probes 很敏感。
数据量在千万级以内、对延迟敏感、写入不频繁的场景，通常选 HNSW。
